# Audio Files

This directory contains audio files for the game. Due to file size, audio files are not included in the repository.

## Required Audio Files

### Music Tracks (public/audio/music/)
- `lobby.mp3` - Background music for lobby/waiting room
- `shop.mp3` - Background music for shop phase
- `race.mp3` - Background music for race phase

### Sound Effects (public/audio/sfx/)
- `button_click.mp3` - UI button clicks
- `purchase.mp3` - Purchasing horses/items
- `sell.mp3` - Selling horses/items
- `bet_place.mp3` - Placing bets
- `race_start.mp3` - Race starting sound
- `race_finish.mp3` - Race finishing sound
- `stumble.mp3` - Horse stumbles during race
- `surge.mp3` - Horse surges forward during race
- `victory.mp3` - Player wins/advances
- `defeat.mp3` - Player loses/eliminated
- `ready_up.mp3` - Player clicks ready button

## Where to Get Audio

You can find free audio files at:
- [Freesound.org](https://freesound.org/)
- [OpenGameArt.org](https://opengameart.org/)
- [Incompetech.com](https://incompetech.com/) (for music)
- [ZapSplat.com](https://www.zapsplat.com/)

## Format Recommendations

- Format: MP3 (best browser compatibility)
- Sample Rate: 44.1kHz
- Bit Rate: 128-192 kbps for music, 64-128 kbps for SFX
- Keep files small (<500KB for SFX, <3MB for music)
